# 华夏文明 · ChinaCiv（GitHub Pages 静态构建）

静态网页游戏，入口是根目录的 `index.html`，需要支持 WebGL2 的浏览器。发布说明和测试范围见 `PUBLISH-NOTE.txt`，地图绘制代码的许可见 `LICENSE-USACIV.txt`。

## 本次修复

- 顶栏：1366/1280 笔记本、iPad 横屏和手机上，右侧「目标」「菜单」按钮会被挤出屏幕。现在这两个按钮固定在右侧，较窄的屏幕会隐藏顶栏的品牌文字和试验情景标签，地图左下角的试验情景说明仍然保留。
- 底栏：宽度 ≤ 860px（iPad 竖屏、手机）时，「结束季度」按钮在屏幕外，游戏无法继续。现在底栏在窄屏下分成两行。
- 底栏高度把 iOS 底部安全区算进去了。这一项没有在真机上测过。
- 华夏图鉴：「战役中：第 3 季度起开放开放」重复字样。
- 华夏图鉴：评级分数线写成了 S≥85/A≥72/B≥60/C≥48，和实际评分代码（S≥90/A≥80/B≥66/C≥52）不一致，已按代码改正。
- 第一季度报告标题显示「GDP +0.00%」，因为首季没有上一季可比。现在改为显示年化 GDP。
- 游戏内存档列表补上战役季度数，和主菜单的显示保持一致。
- 删除了 `assets/` 下没有被引用的旧版（非 `-v2`）文件。
- 线路升级（公路→铁路、铁路→高铁等）：草稿里的「维护/季」原来按打折后的升级费计算，比通车后实际扣的维护费低（例如成渝铁路升高铁，显示 1.79 亿/季，实际 2.44 亿/季）。现在按该等级新建造价计算，和实际结算一致。
- 华夏图鉴的交通说明补上了工期范围（2–8 个季度），并写明维护费按该等级新建造价计算。
- 任务「第一条线路」的说明改为公路、铁路、高铁都算，和实际判定一致。
