# 变更日志

## 0.2.0 · 2026-11-27 · P1a-02：原版 USACiv 视觉对标重构

- **渲染**：移植 USACiv（MIT，© 2026 Andrej Karpathy）的 Canvas2D 地图绘制代码，放在 `packages/renderer/src/usaciv/`，覆盖地形马赛克、耕地拼块、森林、丘陵、山脉、雪峰、水体与海岸泡沫、河流、分区色带、城市分级美术、公路铁路、城镇旗标和 LOD。许可与改动见该目录的 `NOTICE.md`。
- **适配层**：新增 `usacivWorld.ts`，把合成 `RenderView`（米，y 向上）映射到 USACiv 世界模型（公里，y 向下）。odd-r 尖顶布局与奇偶性保持不变。地表覆盖、地势、近海水深、9 个合成分区、路网六边形连线和透镜定义，都由合成地形推导。
- **AtlasRenderer**：保持 Three.js/WebGL2 路线。USACiv 绘制器把视野加 160 px 边距画进缓存画布，再作为纹理贴到正交相机下的四边形上。平移和缩放只移动 GPU 相机；视野超出缓存、缩放超过 2 倍，或缩放停稳 140 ms 后才重绘。悬停、选中和旗标画在 2D 覆盖层上。原来的 `terrain.ts`、`sprites.ts`、`lines.ts` 已删除。
- **界面**：按 USACiv 的设计重做并本地化为中文。40 px 深蓝顶栏包含徽记、区域合计、搜索和按钮；右下是透镜坞和“地图”图层弹层，左下是小地图、合成标识和比例尺，右侧是城镇/地块/线路详情面板。另有悬停提示、透镜图例、金色选中框。图标改用 USACiv 的代码绘制图标集。
- **合成数据**：夹具新增 46 个确定性合成聚落（名称由固定字表组合，描述标明“合成”）。首页视野改为框住全流域（宽 3,300 km）。城市美术按人口×4 分档，界面显示的人口保持原合成值。
- **测试**：e2e 改用新 UI 的入口（图层弹层、二级标题、首页无默认选中），增加 LOD、旗标和静态重绘断言。路线拾取改在放大到路网显示后进行。新增适配层单元测试 5 项。导出文件名改为 ASCII（`chinaciv-qinglan.png`）；本环境的 Chromium 158 下，中文文件名会被改成 `download`。
- **基准**：`bench.mjs` 增加静态层重绘次数与耗时、旗标数和经过的 LOD 档位。
