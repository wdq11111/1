# P1a-01 Cloud 测量约定

测量前登记于 2026-11-27。场景为固定种子青澜流域，1440×900 CSS px / DPR 1，Chromium/Linux 无头软件 WebGL2。脚本读取实际 UA、浏览器版本、GPU 字符串和绘图缓冲尺寸。每次以新浏览器上下文加载，冷态从导航开始到地图首帧数值可见。热态预热 5 秒后，按 8 段固定相机路径累计采样 12 秒。脚本记录 rAF 帧间隔 P50/P95/最大值和 renderer.render 的 CPU 侧耗时，两者不等价。记录 >50 ms 间隔次数、绘制调用、三角形、实例、纹理估算。软件渲染结果用于可复现性和回归诊断。

初始桌面体验目标参考基线 §15 平均 ≤16.7 ms，P95 ≤20 ms，绘制 ≤150 次，三角形 ≤300,000。iPad 初始假设为平均 ≥30 fps、P95 ≤40 ms，且地图核心交互可用。此处登记的 Cloud 代理测试最低条件为 WebGL2 可渲染，数值有限，示例可操作且无脚本或着色器错误。正式 P1a-A5 需基线参考硬件、全部压力 Pass、60 秒采样与 iPad 真机阈值批准后复测。
